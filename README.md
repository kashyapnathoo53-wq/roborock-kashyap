# RoboRock India

Intelligent Home Robotics web experience for RoboRock India.

## Features
- **Editorial Refined Light-Only Theme**: Locked to Alabaster White (`#FFFFFF`, `#FCFBF9`), Warm Ivory Cream (`#F6F1EB`), Warm Brown tones, and Roborock Brand Red (`#EA0029`).
- **Flagship Showcase Hero**: Split-column layout featuring official Roborock branding, `2026 NEW LAUNCH`, `ALL NEW SAROS SERIES`, and a side-by-side dock showcase for Saros 20 Pro, S8 MaxV Ultra, and Qrevo Slim.
- **Precision Section Gapping**: Consistent `0.3cm` spacing between sections for a seamless, unified flow.
- **Core Architecture Showcase**: 5-tab interactive architecture exploring LiDAR mapping, hyper suction, anti-tangle rollers, and docking.
- **Live Floor Scrub Simulator**: Interactive interactive canvas revealing spotless white floor underneath.
- **Indian Rupee Catalog (₹)**: Localized product lineup with specification chips, key features, and shopping cart integration.
- **Customer Stories & FAQ**: Verified homeowner reviews and accessible accordion support.
- **In-Home Demo Booking**: Modal drawer for booking free in-home cleaning demos across Indian cities.
